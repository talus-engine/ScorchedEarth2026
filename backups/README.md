# Indigo project backups

`indigo-before-earth-2026-2026-10-25.talus` is the native File → Export project
backup captured before installing the Scorched Earth 2026 branding. It includes
the original level data, WFC artist painting and shared assets. Import it through
Talus's normal project import flow to restore a copy.

The adjacent manifest records its SHA-256 and successful SQLite integrity check.
The 25 MB archive is retained locally and excluded from Git; the manifest is tracked.
