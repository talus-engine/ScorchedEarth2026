## E41 — Seeded runtime brush Spin, Size LFO and shaped erasure

The native behavior already exists: `MazeStrokeBrushSettings` carries `rotationDeg`, `rotationStepDeg`, `lfoAmplitudePx`, `lfoFrequencyHz` and spacing; maze adapters/renderers evaluate it. The editor also has shared effective-size/mask handling in `LiveEditorController`. However, runtime `TerrainWorkSpec` offers recipe/mixture/neural/growth/geometry/ridge, with no pure-noise stroke plus these dynamics. Current runtime generation parameters also cannot target maze stroke dynamics. Do not approximate spin/LFO with per-frame script stamping or accept ignored fields.

**Additional user direction:** run all terrain decoration/growth passes, then clear foreground space using a large spinning flower-shaped eraser, an EMPTY-heavy semantic brush, or both. Latest clarification: clearing should be light and imperfect, not a perfectly empty corridor; preserve the ground silhouette and leave other layers/living bodies alone. Do **not** reimplement that supported path or keep skipped central sites as a substitute. The missing capability is native shaped strokes with dynamics, including eraser material policy. Expose a stable brush shape ID and portable custom shape assets if the chosen flower comes from the user's brush library; do not assume a built-in `flower` ID exists. EMPTY-only erasure must not require a new particle material or painting a transparent color.

Expose/reuse the native bounded stroke evaluator through public runtime terrain work and declarations. Support a pure-noise source, native brush shape, path, base size/angle, spin per stamp, size-LFO amplitude/frequency and explicit deterministic sampling/phase. The game will choose amounts from a separate seeded terrain stream. Rotation must affect a noncircular native brush footprint; do not silently rotate only a circular mask and call it accepted. Define duration/arc-length semantics so identical seeds/paths reproduce independently of rendering speed, job tiling, camera visits and pause. Keep bounds, optional exclusions, budgets, material policy, all-or-refuse commit, cancellation and save barriers. Scorched Terra preserves the foundation and ground silhouette while gently clearing foreground pockets after all detail/growth passes. Reuse native code rather than another script or noise implementation.

Acceptance: the same seeded path yields the same physical material mask after save/reopen and under different job scheduling; two different seeds visibly change spin and size modulation. Compare to native editor/maze brush behavior. Include ±/zero spin where supported, zero/nonzero LFO, clipped bounds, protected floor/corridor and explicit refusal of unsupported combinations.
